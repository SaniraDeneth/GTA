# Branching

- `dev` is the default development branch.
- `live` is the production branch.
- Feature branches: `feature/akindu-auth`, `feature/rihaz-admin`, `feature/thanish-teams`, `feature/yuwandhi-public`, `feature/tharushi-submissions`.

Create every feature branch from `dev` and open pull requests into `dev`. Only approved, tested changes move from `dev` to `live`. Do not push directly to either shared branch.
